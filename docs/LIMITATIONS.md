# Limitations and failure modes

This is a research reproduction repository. A passing command is evidence that the executed assertions held; it is not evidence that every biological or statistical interpretation is justified. Here, PCA means principal component analysis and H1 means first-dimensional homology. **A [separate methodological correction notice](../paper/METHODOLOGICAL_CORRECTIONS_2026-10-09.md) explicitly withdraws unsupported residualized classifier significance claims and clarifies the metric-gated methylation result.**

## What breaks in a clean checkout?

- **Missing tools or dependencies.** The documented Linux quickstart requires Git, Python 3.11, a working `venv` installation, `pip`, `sha256sum`, and connectivity to GitHub and package indexes. The `requirements.txt` pins packages but not operating-system libraries. Installation outside the GitHub Actions environment is not benchmarked.
- **Untrusted serialized checkpoints.** The two pilot figure scripts call `pickle.load` on files under `results/pilot_GSE81089/checkpoints/`. Python pickle deserialization can execute code. Do not replace these files with data from an untrusted source or treat them as a public upload format.
- **Damaged inputs.** `sha256sum -c checksums.sha256` detects byte changes only for paths listed in that registry. A missing or changed registered file makes verification fail; a successfully hashed file is not proof that the scientific protocol is sound. The CPTAC conditional-null experiment independently checks two explicit input hashes.
- **External data access.** `--full`, `--replication`, `--ablation`, and `--confound` can fetch from the Gene Expression Omnibus (GEO), Proteomic Data Commons (PDC), or Genomic Data Commons (GDC). Network failures, changed API responses, insufficient permissions, or a changed upstream matrix can prevent completion or change a result. The default figure path does not fetch upstream data.
- **Generated files in different places.** The pilot writes to `reproduce_output/`, while cohort scripts write alongside their own code and audit scripts accept explicit result directories. `reproduce.py` does not consolidate all outputs into one folder.

## Which statistical comparisons do not justify stronger claims?

- **A single loop statistic is not a mechanism.** Maximum finite H1 persistence describes the longest barcode interval. It does not identify a cell type, biological process, tumor subtype, or cause.
- **Gaussian and feature-shuffle nulls discard dependence.** Both can produce a small reference distribution even when observed H1 is attributable to covariance, batch effects, or other ordinary multivariate structure. A positive excess above these nulls is not evidence that higher-order topology uniquely explains the data.
- **Class-conditioned residualization contaminates the historical AUC evaluation.** `confound_audit_common.residualize_class_mean` uses each sample's observed tumor/normal label to center its data before `cv_auc` splits the samples. Therefore the reported cross-validated area under the receiver operating characteristic curve (AUC) on these residuals is not a held-out predictive evaluation. `auc_collapse_permutation_test` permutes labels while leaving the label-dependent features fixed, so those p-values cannot be interpreted as valid class-label permutation inference. The GSE146889 clean-lineage reconciliation already withholds the corresponding invalid significance interpretation. Do not cite old residualized AUC values as evidence that prediction has been removed.
- **The historical residualized null comparison is not transform-matched.** `residualization_control` computes the observed residualized PCA statistic, but `gaussian_null_maxh1` and `permutation_null_maxh1_pca_refit` do not reapply the same class-label residualization to every null. The later CPTAC follow-up fixes this *particular* comparison for one cohort; the historical cross-cohort residualization conclusions are not automatically repaired.
- **The CPTAC conditional-null analysis destroys covariance.** `audit/cptac_resid_null/experiment.py` preserves empirical per-protein distributions *within* tumor and normal groups but independently shuffles each column. The archived 499-draw result is a sensitivity to that null, **not** a covariance-spectrum-preserving control. It assumes conditional sample exchangeability; patient pairing, aliquot dependence, and batch structure were not individually controlled by that code.
- **TCGA methylation is metric-dependent.** The methylation driver limits PCA to 35 components for 36 observations and reports a zero maximum H1 persistence in a derived spectral-distance space. Because PCA(35) retains the sample-centered Euclidean geometry, the spectral result must not be described as a loop destroyed by PCA itself. The Euclidean and spectral measurements ask different questions.
- **Multiple testing and pilot status matter.** `prereg/PREREGISTRATION.md` distinguishes the exploratory GSE81089 pilot from later cohorts. Its family of Benjamini–Hochberg (BH) false discovery rate (FDR) comparisons is not interchangeable with post-hoc nulls or newly developed sensitivity tests. The 499-draw CPTAC follow-up is not an additional preregistered confirmation.

## What are the runtime and scaling ceilings?

- **Expensive branches are opt-in.** `reproduce.py --full` runs the full pilot null counts regardless of `--n-draws`. Other phases accept `--n-draws` as a reduced-draw cap, which changes Monte Carlo resolution and can substantially change tail estimates.
- **The parameter sweep creates a worker pool.** `code/ablation_sweep/02_run_sweep.py` defaults to four workers, uses per-configuration pickles, and accumulates a JavaScript Object Notation (JSON) checkpoint. There is no automatic memory budget or cross-platform performance guarantee. Existing results include measured per-configuration time, but fresh hardware performance is not benchmarked here.
- **Failed sweep tags can be skipped after restart.** The sweep persists an entry with `FAILED: true` on an exception and later constructs `done_tags` from every saved entry. A resumed run will skip that tag until its checkpoint record is repaired. Do not treat `SWEEP COMPLETE` as proof that no entries failed.
- **Persistent homology cost grows with sample count.** These scripts form Vietoris–Rips constructions with `ripser` or GUDHI and perform repeated null draws. The repository does not provide a demonstrated large-cohort scaling bound, memory ceiling, or distributed general-purpose scheduler. Performance beyond the recorded cohorts is **not benchmarked**.
- **Conditional-null runtime guards are partial.** `experiment.py` checks a wall-clock limit between draws; it cannot interrupt a single long-running ripser call. Its GitHub Actions workflow also has a job timeout. No parallel 499-draw execution is implemented in that script.

## Which data and reproduction boundaries should reviewers know?

- **Reproducibility depth varies.** `audit/gse146889_clean_lineage/` independently re-executes one previously transcript-reconstructed audit under its own input and provenance records. That does not make every historical stage independently reconstructed.
- **Metadata inventories can lag.** `MANIFEST.md` is a file inventory and `checksums.sha256` is a byte-verification list, not substitutes for checking the Git commit, scripts, actual executed parameters, and reports. Prefer the currently checked-out tree when determining which files exist.
- **Some paths are not covered by the MIT code license.** `LICENSE` explicitly limits its license note to `code/` and excludes manuscript text and figures from that note. Do not infer that datasets, figures, or the manuscript have identical reuse rights.
- **No universal library or service contract exists.** There is no published HTTP API, package-installable Python API, model-serving endpoint, cloud deployment, or guarantee of binary-stable images. Phase outputs are research artifacts with different schemas.
- **No automatic manuscript reconciliation.** A new sensitivity result does not change `paper/`, historical CSV files, the original preregistration, or submitted copies of the manuscript. Interpret the current paper beside the more recent audit records.
